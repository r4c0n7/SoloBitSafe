Privacidad

SoloBitSafe no recopila datos personales. No hay cuentas, ni analítica, ni publicidad, ni seguimiento – ni en esta web, ni en la app, ni en el dispositivo. Aquí está cada punto en el que los datos salen de tus manos, y hacia quién.

Esta web

La web está alojada en GitHub Pages. GitHub procesa tu dirección IP para entregar las páginas (consulta la declaración de privacidad de GitHub). La web no usa cookies.

Las fuentes y las imágenes se sirven desde esta web. El modelo 3D y el flasheador web cargan sus scripts desde jsDelivr (cdn.jsdelivr.net), que ve tu dirección IP.

El flasheador web solo habla con tu placa después de que la elijas en el diálogo del navegador. El firmware viene de esta web; no se sube nada.

La app

Todo se queda en tu móvil u ordenador: descriptores de solo lectura, etiquetas, contactos y ajustes. La semilla nunca llega a la app.

Para mostrar saldos e historial, la app consulta los servidores Electrum o Esplora que elijas (por defecto servidores públicos como electrum.blockstream.info o mempool.space). Esos servidores ven tus direcciones y tu IP. Puedes usar tu propio servidor o Tor.

Permisos de Android: Bluetooth / dispositivos cercanos para hablar con la placa, ubicación solo porque versiones antiguas de Android la exigen para buscar por Bluetooth, USB para la conexión por cable, huella para el bloqueo opcional de la app. Nada de esto se nos envía.

El dispositivo

La semilla se guarda cifrada en la placa y nunca sale de ella. Los ajustes y contactos se quedan en la placa.

La placa se conecta a tu Wi-Fi, al pool de minería que configures (que ve tu dirección de cobro), a mempool.space para altura de bloque, saldo y comisiones, y a CoinGecko para el tipo de cambio.

Su panel web carga fuentes de Google Fonts en tu navegador.

Donaciones y contacto

Las donaciones son transacciones de Bitcoin y por tanto públicas en la blockchain. Las preguntas y avisos van por el repositorio de GitHub de esta web.

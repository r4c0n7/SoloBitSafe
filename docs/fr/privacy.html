Confidentialité

SoloBitSafe ne collecte aucune donnée personnelle. Pas de compte, pas d'analyse, pas de publicité, pas de pistage – ni sur ce site, ni dans l'appli, ni sur l'appareil. Voici chaque endroit où des données quittent tes mains, et vers qui.

Ce site

Le site est hébergé sur GitHub Pages. GitHub traite ton adresse IP pour livrer les pages (voir la déclaration de confidentialité de GitHub). Le site ne dépose aucun cookie.

Les polices et les images viennent de ce site. Le modèle 3D et le flasheur web chargent leurs scripts depuis jsDelivr (cdn.jsdelivr.net), qui voit ton adresse IP.

Le flasheur web ne parle à ta carte qu'après que tu l'as choisie dans la fenêtre du navigateur. Le firmware vient de ce site ; rien n'est envoyé.

L'appli

Tout reste sur ton téléphone ou ton ordinateur : descripteurs en lecture seule, libellés, contacts et réglages. La graine n'atteint jamais l'appli.

Pour afficher soldes et historique, l'appli interroge les serveurs Electrum ou Esplora que tu choisis (par défaut des serveurs publics comme electrum.blockstream.info ou mempool.space). Ces serveurs voient tes adresses et ton adresse IP. Tu peux utiliser ton propre serveur ou Tor.

Autorisations Android : Bluetooth / appareils à proximité pour parler à la carte, localisation uniquement parce que les anciennes versions d'Android l'exigent pour la recherche Bluetooth, USB pour la connexion par câble, empreinte pour le verrouillage optionnel. Rien de tout cela ne nous est envoyé.

L'appareil

La graine est stockée chiffrée sur la carte et ne la quitte jamais. Les réglages et les contacts restent sur la carte.

La carte se connecte à ton Wi-Fi, au pool de minage choisi (qui voit ton adresse de paiement), à mempool.space pour la hauteur de bloc, le solde et les frais, et à CoinGecko pour le cours.

Ses pages web ne chargent rien de tiers ; les polices sont celles de ton ordinateur.

Dons et contact

Les dons sont des transactions Bitcoin, donc publiques sur la blockchain. Questions et signalements passent par le dépôt GitHub de ce site.

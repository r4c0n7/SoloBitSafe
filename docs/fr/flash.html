Flasher dans le navigateur

Branche ton LilyGo T-Display-S3 et installe SoloBitSafe directement depuis cette page : en mise à jour qui garde ton portefeuille, ou en installation complète sur une carte neuve.

  1. Utilise Chrome ou Edge sur un ordinateur (Windows, Linux, macOS) et un câble USB-C de données.
  2. Ferme l'app SoloBitSafe, Sparrow et tout ce qui utilise l'appareil en USB.
  3. Appuie sur le bouton, choisis « USB JTAG/serial debug unit » dans la fenêtre du navigateur et laisse l'onglet ouvert jusqu'à « terminé ».
  4. Si la connexion échoue : débranche l'appareil, maintiens BOOT (BTN1) en le rebranchant, relâche et recommence.
  5. Sous Linux, Chrome peut perdre la connexion quand la puce passe en mode téléchargement. Utilise Windows ou macOS pour l'instant.

Détails


Le firmware est signé par SoloBitSafe et vérifié en SHA-256 avant l'écriture. Les appareils avec Secure Boot ne démarrent qu'un firmware signé.









Les dépôts du firmware et de l'appli sont privés pour l'instant. Code source de ce site


Construit sur NerdMiner V2 de BitMaker (MIT), trezor-crypto (MIT), Argon2 (CC0/Apache 2.0), TFT_eSPI, NimBLE-Arduino. Polices : Barlow et JetBrains Mono (SIL OFL).

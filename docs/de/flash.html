Im Browser flashen

Steck dein LilyGo T-Display-S3 an und spiel SoloBitSafe direkt von dieser Seite auf – als Update, das deine Wallet behält, oder als Komplett-Installation auf einem neuen Board.

  1. Chrome oder Edge auf einem Computer (Windows, Linux, macOS) und ein USB-C-Datenkabel verwenden.
  2. SoloBitSafe-App, Sparrow und alles andere schließen, was das Gerät über USB nutzt.
  3. Knopf drücken, im Browser-Dialog „USB JTAG/serial debug unit“ wählen und den Tab offen lassen, bis „fertig“ erscheint.
  4. Klappt die Verbindung nicht: Gerät abziehen, BOOT (BTN1) gedrückt halten und wieder einstecken, loslassen, neu starten.

Details


Die Firmware ist von SoloBitSafe signiert und wird vor dem Schreiben per SHA-256 geprüft. Geräte mit Secure Boot starten nur signierte Firmware.









Die Repositories von Firmware und App sind vorerst privat. Quelltext dieser Website

Flash in the browser

Plug in your LilyGo T-Display-S3 and install SoloBitSafe straight from this page – as an update that keeps your wallet, or as a full install on a new board.

  1. Use Chrome or Edge on a computer (Windows, Linux, macOS) and a USB-C data cable.
  2. Close the SoloBitSafe app, Sparrow or anything else that uses the device over USB.
  3. Press the button, choose “USB JTAG/serial debug unit” in the browser dialog and keep the tab open until it says done.
  4. If the connection fails: unplug the device, hold BOOT (BTN1) while plugging it back in, release, start again.
  5. On Linux, Chrome can lose the connection when the chip switches to download mode. Use Windows or macOS for now.
